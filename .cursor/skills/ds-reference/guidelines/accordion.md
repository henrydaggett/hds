# DsAccordion guidelines

## When to use

- Use a DsAccordion for content people scan and open selectively, like FAQs or optional settings.
- Don't hide content most people need; show it directly.
- Use DsTabs when sections are peers the user switches between.

## Content

- Write titles as short questions or topics, in sentence case.
- Keep each panel focused on its title.

## Layout

- Start with all items closed unless the input shows one open.
- Give an accordion the full width of its column.
