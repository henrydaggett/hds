# HdsMenu guidelines

## When to use

- Use a HdsMenu to group secondary actions behind one button, like Edit / Duplicate / Delete on a row.
- Keep the main action as its own visible HdsButton, not in a menu.
- Use a HdsSelect to choose a value; a menu runs actions.

## Content

- Start item labels with a verb, in sentence case: "Rename", "Move to folder".
- Put destructive items last, after a separator, in red.

## Layout

- Use `align="end"` when the trigger sits at the right edge of a row or card.
