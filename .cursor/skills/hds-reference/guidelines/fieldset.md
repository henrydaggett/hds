# HdsFieldset guidelines

## When to use

- Use a HdsFieldset to split a longer form into titled sections, like "Billing details" and "Shipping address".
- Don't use a HdsFieldset for a short form with a single group of fields.
- Don't use a HdsFieldset just to title one HdsCheckboxGroup; use the group's label.

## Content

- Keep legends short nouns that name the section.
- Use the description for one line of context about the section.

## Layout

- Place Fieldsets directly inside a HdsForm, one after another.
- Don't nest Fieldsets.
- Keep buttons outside Fieldsets, in HdsFormActions at the end of the HdsForm.
