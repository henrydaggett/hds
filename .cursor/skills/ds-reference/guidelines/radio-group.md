# DsRadioGroup guidelines

## When to use

- Use a DsRadioGroup when exactly one of a few options (two to five) must be chosen and all should be visible.
- Use a DsSelect for more than about five options.
- Use a DsCheckboxGroup when more than one option can be chosen.
- Use a DsToggleGroup for switching views or modes in a toolbar.

## Content

- Give the group a label that asks the question: "Billing period", "Delivery".
- Keep option labels short, in sentence case, and in a logical order.
- Preselect an option only when there's a sensible default.

## Layout

- Stack options vertically by default. Use horizontal for two or three short options.
