# DsTabs guidelines

## When to use

- Use DsTabs to split related content on one page into sections the user switches between, like Overview / Activity / Settings.
- Use a DsToggleGroup to switch how the same content is shown (List / Board).
- Don't use tabs for steps the user must complete in order.

## Content

- Use one or two words per tab, in sentence case.
- Two to six tabs. More than that needs a different layout.

## Layout

- Put tabs at the top of the content they control, full width of that area.
