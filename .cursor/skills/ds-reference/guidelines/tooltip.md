# DsTooltip guidelines

## When to use

- Use a DsTooltip to name an icon-only control or add a short hint to a button.
- Don't put essential information in a tooltip; it's hidden until hover and unreachable on touch screens.

## Content

- A few words, sentence case, no full stop: "Copy link", "Creates an empty project".
- Don't repeat the button's visible label.
