# HdsSelect guidelines

## When to use

- Use a HdsSelect to choose one option from a list of about four or more.
- Use a HdsToggleGroup for two or three options that should all be visible.
- Use a HdsCheckboxGroup when more than one option can be chosen.

## Content

- Always give the select a visible label with a HdsField, unless it sits in a toolbar.
- Use a placeholder that prompts the choice: "Select a country".
- Keep option labels short and order them logically (alphabetical, by size, or by frequency).
- Only preselect an option when there's a sensible default.

## Layout

- Selects fill their container, like HdsTextInput.
- Use the same size as the inputs around it.
